### Stratum
Ask plain-English questions of databases nobody documented. The model writes SQL against a clean virtual schema, and a deterministic compiler rewrites it for the messy real one.

**23.9% to 60.9%** execution accuracy on a deliberately messy Chinook database, same model, with **47% fewer tokens** per question.

`Python` `FastAPI` `PostgreSQL` `Next.js`

### AI Development Team
A five-agent software team on LangGraph. The testing agent actually runs the code, and every routing decision is plain Python, not a model's opinion.

Scored on a benchmark of **12 tasks and 66 hidden test cases** that the agents never see.

`Python` `LangGraph` `FastAPI` `Docker`

### PJM Energy Demand Forecast
Seven-day electricity demand forecasts for the PJM East grid, with calibrated prediction intervals. The trained model runs in JavaScript on Cloudflare.

**2.14% MAPE** on a 905-day hold-out, with RMSE **66% lower** than the "same as yesterday" baseline.

`Python` `scikit-learn` `JavaScript` `Cloudflare`

[Live site](https://energy-prediction-mll.wm-waleedmaqbool.workers.dev) · [Code](https://github.com/waleed-w-maqbool-m/Energy-Prediction-ML)
